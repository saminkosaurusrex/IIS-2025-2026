Instalace

Postup Inštalácie na server (Endora)

  • Projekt beží na Endora hosting-u spolu s mysql databázou
  • Bolo potrebné preniesť celú databázu na hosting
  • Export prebehol cez príkaz: mysqldump -p iis > kino.sql
  • Vygenerovaný súbor kino.sql sa následne importoval do databázy na Endore (cez phpMyAdmin)
  • Frontend (Vue) sa musel zbuildovať do finálnych JS/CSS súborov: npm run build
  • Build sa cez FileZilla nahral na Endoru
  • Do public_html sa umiestnili:
    • obsah z build/ (build Vue)
    • index.php
    • .htaccess
    • storage
  • Do priečinka /www sa nahrala celá Laravel aplikácia okrem node_modules a nepotrebných súborov
  • Bolo potrebné upraviť cestu ukladania súborov (storage path), aby zodpovedala štruktúre Endora hostingu
  • Skontrolovalo sa nastavenie ENV súboru:
    • DB_HOST, DB_DATABASE, DB_USERNAME, DB_PASSWORD
    • APP_URL na doménu Endory
    • APP_ENV=production, APP_DEBUG=false na produkčný režim

Softwarové požiadavky

Pri vývoji bol použitý framework Laravel spolu s vue starter kit: bližšie informácie z dokumentácií od Laravelu

  • PHP 8.2+
  • Web server
  • Composer pre správu balíčkov
  • Databázový server MySQL

Lokálny setup

  • Stiahnutie zip z githubu: https://github.com/saminkosaurusrex/IIS-2025-2026
  • Odzipovanie
  • Inštalácia PHP závislostí: composer install
  • Inštalácia Node.js závislostí: npm install
  • Vytvorenie .env suboru: cp .env.example .env
  • Editácia:
    • APP_URL=http://localhost:8000
    • DB_CONNECTION, DB_DATABASE, DB_USERNAME, DB_PASSWORD podľa vlastných hodnôt
  • Generácia APP_KEY pomocou: php artisan key:generate
  • Vytvorenie a naplnenie databáze skusobnými dátami: php artisan migrate:fresh --seed
  • Spustenie aplikácie: composer run dev

Známé problémy

Pri pridaní nového druhu predstavenia sa položky v navigačnom paneli (navbar) neaktualizujú okamžite. Z dôvodu cacheovania sa zmeny prejavia po 1 hodine.
